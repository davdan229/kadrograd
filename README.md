# Кадроград

Русскоязычное расширение для **Cloudstream на Android**. Ищет фильмы, сериалы, мультфильмы и аниме в подключённых каталогах. Год выпуска не ограничен. Видео воспроизводится с серверов источников.

## Установка и обновление

1. В Cloudstream откройте **Настройки → Расширения → Добавить репозиторий**.
2. Вставьте адрес и установите расширение **Kadrograd**:

   ```text
   https://raw.githubusercontent.com/davdan229/kadrograd/main/repo.json
   ```

3. Для обновления откройте этот же репозиторий в приложении. Если источник не появился, перезапустите Cloudstream.

[Открыть репозиторий в Cloudstream](https://cs.repo/?raw.githubusercontent.com/davdan229/kadrograd/main/repo.json). `KG-RU-2026` — идентификатор проекта; для установки нужен адрес выше.

## Поиск и просмотр

Откройте общую вкладку **«Поиск»** и включите нужные источники в фильтре. Cloudstream ищет по подключённым каталогам. Найденная карточка показывает, что произведение есть в каталоге; наличие видео проверяется после выбора фильма или серии.

- **Качество.** В меню **«Источники»** видны опубликованные и доступные варианты. Расширение предлагает 1080p первым, сохраняя другие разрешения, в том числе 4K там, где его отдаёт поддерживаемый плеер. Профиль качества Cloudstream может изменить порядок или скрыть отдельные варианты. Фильтр **«Только 1080p и выше»** выключен по умолчанию.
- **Значки 4K и «Дуб».** После проверки потоков Zona при следующем открытии каталога или поиска на постере появятся подтверждённые значки, если они включены в настройках Cloudstream. У сериала значок относится к проверенной серии.
- **Озвучка.** В Zona можно выбрать отдельный пункт с названием студии или открыть многодорожечный поток и переключить звук в меню **«Аудио»**. Список зависит от выбранной серии и разрешения. Именованный пункт предлагает 1080p при наличии, иначе лучшее доступное разрешение для этой дорожки.
- **Субтитры.** Выбираются в плеере, когда их передаёт источник.
- **Пропорции.** Выберите **«Подогнать» (Fit)** в плеере. Например, 1920×800 — исходный широкоформатный кадр. Расширение сохраняет его размеры и не перекодирует видео.

## Источники

| Источник | Что доступно |
| --- | --- |
| **Zona** | Фильмы, сериалы, мультфильмы, мультсериалы и аниме. DASH и HLS с выбором качества и звука; прямые MP4/HLS как дополнительные варианты. На Chromecast доступны только прямые потоки. Скачивание в расширении отключено: [справка Zona](https://az1.zona.pub/faq) указывает на ограничение для аккаунтов без премиума. |
| **AniLibria** | Аниме с озвучкой AniLibria. HLS 480p, 720p и 1080p при наличии. Доступна кнопка скачивания Cloudstream. |
| **AnimeVost** | Аниме с веб-зеркала `v14.vost.pw`. Разрешение зависит от опубликованных MP4. Доступна кнопка скачивания Cloudstream. |
| **KinoVibe, HDRezka, Filmix** | Дополнительные адаптеры, выключены по умолчанию. KinoVibe выдаёт гостевое SD; HDRezka и Filmix могут не выдавать рабочие ссылки. |

Адреса источников и дополнительные адаптеры настраиваются через шестерёнку расширения. После изменения набора источников перезапустите Cloudstream.

## Доступ из разных стран

Расширение не ограничивает страны. Запросы идут напрямую к источникам, без прокси Кадрограда. Если один из двух адресов Zona для запуска плеера не отвечает, расширение может продолжить через второй. Доступность каталога, видеосервера и отдельных релизов зависит от страны, провайдера и ограничений источника. Если один каталог недоступен, можно поискать произведение в другом включённом источнике.

## Что проверено

Результаты автоматических тестов и проверки пакета доступны в [GitHub Actions](https://github.com/davdan229/kadrograd/actions/workflows/build.yml).

Проверки выполнялись HTTP-запросами с компьютера. Они не подтверждают полное воспроизведение, скачивание или интерфейс на конкретном Android-устройстве. При повторных запросах Zona наблюдались HTTP 403 и таймауты. Работа без VPN зависит от сети и доступности самих видеосерверов. Полнота каталогов, наличие каждой озвучки и 4K для всех произведений не гарантируются.

Если возникла проблема, укажите в [Issues](https://github.com/davdan229/kadrograd/issues) версию расширения и Cloudstream, источник, название, сезон и серию, точную ошибку и используете ли VPN. Пароли, cookies и подписанные видеоссылки не нужны.

## Сборка

Нужны JDK 21 и Android SDK Platform 35. На Windows:

```powershell
.\gradlew.bat :Kadrograd:testDebugUnitTest :Kadrograd:make makePluginsJson
python -m unittest discover -s scripts -p test_package_repo.py
python scripts/package_repo.py
```

На Linux используйте `./gradlew`. Пакет Gradle — `Kadrograd/build/Kadrograd.cs3`, файлы репозитория — в `dist/`. GitHub Actions публикует их в ветку `builds`. Список расширений ссылается на пакет по адресу с его SHA-256, поэтому закэшированная версия списка продолжает получать подходящий файл.

Живые проверки запускаются отдельно: `:Kadrograd:testDebugUnitTest -PliveSources --tests '*LiveSourcesCheck' --tests '*ZonaLiveCheck' --tests '*ZonaQualityLiveCheck'`. Результат зависит от внешних сервисов. [Предыдущие отчёты](docs/) · [Сторонний код и авторство](NOTICE.md) · [GPL-3.0](LICENSE).

# Кадроград

Русскоязычный репозиторий расширений для **Cloudstream Mobile**. Фильмы, сериалы, мультфильмы и аниме из внешних каталогов, включая старые релизы. Разделов с пользовательскими роликами, стримами и телевизионными каналами нет.

Идентификатор проекта: **KG-RU-2026**. Текущая версия — **3**, статус — **бета: HTTP/JVM-проверки пройдены, требуется проверка плеера на Android**.

## Установка

В Cloudstream откройте **Настройки → Расширения → Добавить репозиторий** и вставьте:

```text
https://raw.githubusercontent.com/davdan229/kadrograd/main/repo.json
```

Название: **Кадроград**. После добавления установите расширение **Kadrograd**. По умолчанию доступны **Кадроград · AniLibria** и **Кадроград · AnimeVost**. KinoVibe, HDRezka и Filmix включаются отдельно в настройках расширения.

При обновлении с версии 1/2 обновите Kadrograd в списке расширений и перезапустите Cloudstream. Старые карточки HDRezka не переключаются на другой источник автоматически: найдите произведение в KinoVibe или AnimeVost заново.

[Добавить репозиторий через cs.repo](https://cs.repo/?raw.githubusercontent.com/davdan229/kadrograd/main/repo.json) · [Готовый пакет .cs3](https://raw.githubusercontent.com/davdan229/kadrograd/builds/Kadrograd.cs3) · [Сборки](https://github.com/davdan229/kadrograd/actions/workflows/build.yml)

`KG-RU-2026` — собственный идентификатор, а не зарегистрированный короткий код Cloudstream. Для установки используйте полный адрес выше или кнопку cs.repo.

Рекомендуется актуальная Android-версия Cloudstream. Сборка использует текущий API из `classes.jar` ветки pre-release; совместимость со всеми старыми версиями клиента не заявлена.

## Источники и возможности

| Источник | Содержимое | Потоки | Проверка 18.10.2026 |
| --- | --- | --- | --- |
| KinoVibe, опциональный | Фильмы, сериалы по сезонам, мультфильмы и аниме разных лет | Гостевой SD MP4, опубликованная озвучка. Скачивание отключено: сайт требует регистрацию; HD для гостей не выдаётся расширением | HTTP/JVM-проверки проходят с проверочного компьютера; пользователь подтвердил недоступность сайта без VPN в своей сети. Выключен по умолчанию |
| AniLibria | Аниме и полнометражное аниме разных лет | Озвучка AniLibria, 480/720/1080 при наличии | Каталог, поиск, серии, HLS и фрагмент видео подтверждены |
| AnimeVost | Веб-каталог официального зеркала v14.vost.pw, без фильтра по году. API animevost.org больше не используется | Опубликованная озвучка, MP4 720p/480p при наличии; перед выдачей проверяется доступность файла с устройства | Зеркало открывается без VPN в браузере телефона пользователя; HTTP/JVM-проверки нового адаптера описаны в отчёте v3. Проверка самого Android-плагина в сети пользователя ещё требуется |
| HDRezka, нестабильный | Фильмы, сериалы, мультфильмы, аниме, дорамы разных лет | Озвучки, качества, HLS/MP4, субтитры при наличии | Пользователь сообщил недоступность зеркал без VPN и HTTP 2004 в плеере. CDN также недоступен при проверке. Выключен по умолчанию |
| Filmix, экспериментальный | Фильмы, сериалы, мультфильмы | Выбор озвучек и качества, если сайт выдаёт видео | Каталог и поиск доступны; проверенные карточки не выдали видео. Выключен по умолчанию |

**Это не база всех произведений мира.** Состав каталога, озвучки, субтитры, качество и доступ к конкретному релизу определяют сайты. Ограничения по 2026 году нет; будущие обновления источников также могут появляться в каталоге.

AnimeVost дополняет каталог одной команды AniLibria. В частности, проверяются «Тетрадь смерти» (2006, 37 серий), «Монстр» (2004, 74 серии) и «Форма голоса» (2016, фильм). Они служат проверочными примерами; веб-каталог листается без фильтра по году, поиск получает до 50 результатов по названиям. Аудит прежнего API в версии 2: счётчик сообщал 3 610 позиций, фактически возвращался 3 601 уникальный ID. Это исторические данные API, а не новый аудит веб-каталога версии 3.

## Просмотр и скачивание

1. Выберите источник и найдите название по-русски или на языке оригинала, если сайт его индексирует.
2. Для сериала выберите сезон и серию. Доступные потоки показывают озвучку, метку качества и HLS/MP4.
3. Выберите нужный поток. Субтитры HDRezka передаются плееру, когда сайт их предоставляет; встроенные в поток дорожки обрабатывает Cloudstream.
4. Для сохранения видео AnimeVost/AniLibria используйте встроенную кнопку скачивания Cloudstream. Полное скачивание и воспроизведение сохранённого файла на Android ещё не проверены. В KinoVibe скачивание отключено из-за требования регистрации на сайте.

Изменить адрес источника можно через шестерёнку расширения Kadrograd. При смене адреса обновите главную страницу и заново откройте карточку. Там же можно включить KinoVibe, нестабильный HDRezka или экспериментальный Filmix; после изменения набора источников перезапустите приложение. Они не считаются исправленными заменой источников по умолчанию.

## Доступность в России

В версии 3 исправлены единицы таймаутов NiceHttp: секунды больше не передаются как миллисекунды. Для обычного запроса задан таймаут 12 секунд и дополнительный предел ожидания 13 секунд. Для AnimeVost используется веб-зеркало, которое пользователь открыл без VPN; адрес настраивается отдельно от прежнего API. Поиск выполняется по названиям, до пяти страниц результатов, с общим бюджетом 16 секунд. Проверка видеосерверов выполняется с телефона при выборе серии; недоступные файлы не передаются плееру.

Расширение не требует собственного сервера или постоянно включённого компьютера. Запросы идут прямо с телефона к сайтам и их видеосерверам. Внешний VPN не встроен и автоматически не подключается.

**Работа без VPN у всех российских операторов не подтверждена и не гарантируется.** Доступный сайт может выдавать ссылку на заблокированный CDN. Зеркало каталога не исправляет блокировку видеосервера. Проект не снимает ограничения аккаунта, правообладателя или DRM.

## Сборка и проверка

Нужны JDK 21 и Android SDK Platform 35. На Windows:

```powershell
.\gradlew.bat :Kadrograd:testDebugUnitTest :Kadrograd:make makePluginsJson
python scripts/package_repo.py
```

На Linux замените `.\gradlew.bat` на `./gradlew`. Укажите путь к SDK в `ANDROID_HOME` либо `local.properties`. Пакет появляется в `Kadrograd/build/Kadrograd.cs3`, файлы для репозитория — в `dist/`.

GitHub Actions выполняет тесты и публикует согласованный комплект `.cs3`, `plugins.json`, `repo.json` и `SHA256SUMS` в ветку `builds`. Обновление исходников не требует работающей локальной копии.

Проверка новых адаптеров реальными HTTP-запросами с компьютера (отдельно от проверки плеера Android):

```powershell
.\gradlew.bat :Kadrograd:testDebugUnitTest -PliveSources --tests '*LiveSourcesCheck'
```

Она проверяет страницы каталога, поиск, карточки, соответствие серии и MP4-фрагменты в начале файла и со смещением 1 МиБ. Внешние сервисы должны быть доступны во время запуска; эта проверка не включается в обычную CI-сборку.

Диагностика первоначальных источников:

```text
python -m pip install -r scripts/requirements.txt
python scripts/live_smoke.py
```

## Ограничения проверки

Успешная сборка не доказывает работу плеера на телефоне. Перед использованием проверьте в своей сети фильм, сериал, смену озвучки, субтитры и скачивание. При ошибке укажите в Issue версию Cloudstream, версию Android, оператора, источник и название произведения. Не прикладывайте пароли, cookies или подписанные видеоссылки.

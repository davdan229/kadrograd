# Проверка версии 4 — Zona

Дата: 18.10.2026. Версия расширения: 4. Проверялись реальные HTTP-запросы из Kotlin-адаптера с компьютера; плеер Android не запускался. Управление приложениями, браузером и эмулятором не использовалось.

## Изменение

Zona добавлена источником по умолчанию рядом с AniLibria и AnimeVost. Современный сайт `https://w1.zona.im` указан в [официальной справке Zona](https://az1.zona.pub/faq). Пользователь подтвердил доступность сайта и приложения Zona без VPN на телефоне; доступ отдельного плагина к API и CDN через эту сеть пока не подтверждён.

Каталог работает через публичные запросы современного сайта. Шесть разделов: фильмы, сериалы, мультфильмы, мультсериалы, аниме-фильмы, аниме-сериалы. Фильтра по году нет. Поиск читает результаты сайта. Трейлеры и отдельные пользовательские видеоролики не добавляются.

Перед воспроизведением заново проверяются ID произведения и номер серии. Доступны публичные механизмы Mobilink, Filmix и KinoVibe из текущего веб-плеера. Их код не встраивается и не исполняется; адаптер обрабатывает HTTP-формат самостоятельно. Все механизмы плеера Zona не реализованы. Для MP4 проверяется `ftyp`, для HLS — плейлист и первый сегмент. Корректная карточка без доступного видео не становится рабочей ссылкой.

Скачивание выключено: официальная справка требует премиум Zona. Авторизация, премиум и DRM не обходятся.

## Защита от регрессий

Десять контрактных тестов Zona: поиск с кириллицей и `&`, пагинация, фильтрация трейлеров, старые годы, сбор сезонов, соответствие произведения/серии, свежая ссылка, озвучка/качество/субтитры, HTTP 403, недоступный HLS-сегмент, HTML вместо видео с HTTP 200, корректный MPEG-TS и проверка транспортного формата независимыми векторами. Все 49 обычных тестов (39 прежних и 10 Zona) и сборка `.cs3` прошли локально.

Подписанные видеоссылки, содержимое сессий и cookies в отчёт не включены. Сохранённая карточка содержит идентификаторы, а не адрес CDN.

## Границы проверки

Не проверены: декодирование/перемотка в Cloudstream Android, доступ отдельных API/CDN с телефона пользователя, живые субтитры и весь каталог Zona. Полное скачивание не заявлено. Озвучки, возраст каталога и разрешения зависят от ответа сайта, а каталог может содержать карточки без доступного видео. Работа всех произведений, всех дорожек и без VPN у каждого российского оператора не подтверждена.

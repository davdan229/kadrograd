# Клиент Android

Сборка на основе CloudStream 4.8.0 с загрузкой открытых DASH-потоков и HLS с отдельным звуком. Видео и выбранная озвучка сохраняются без перекодирования: VP9/Opus сохраняются в WebM с помощью Media3, совместимые MP4-потоки сохраняются в MP4. Исходное разрешение сохраняется; отсутствующие у источника варианты качества не создаются.

Приложение сохраняет название и интерфейс CloudStream и устанавливается рядом с официальной сборкой. Изменения основаны на закреплённой ревизии из `upstream.json`; исходники CloudStream не копируются в этот репозиторий. Скрипт проверяет контрольные суммы изменяемых файлов, применяет изменения и добавляет файлы из `overlay`.

[Скачать 1.0.0-beta.4](https://github.com/davdan229/kadrograd/releases/tag/client-v1.0.0-beta.4). Обновление устанавливается поверх предыдущей сборки Кадрограда без удаления. На Android 13 проверены выбор качества и озвучки по обычной кнопке скачивания, сохранение тестовых DASH-потоков в 480p, 720p, 1080p, 1440p и 4K, пауза и отмена, прогресс в интерфейсе и уведомлениях, просмотр скачанного без сети после остановки процесса. Отдельная проверка вызывает аварийное завершение и подтверждает, что сохранённую очередь можно отменить без повторного запуска загрузок. [Проверки выпуска](https://github.com/davdan229/kadrograd/actions/runs/43177836807).

```sh
git clone https://github.com/recloudstream/cloudstream.git upstream
git -C upstream checkout 3796406e636356f556c16e04e1da4e37d6a19038
python3 client/prepare.py upstream
./gradlew :Kadrograd:make makePluginsJson
python3 client/bundle_sources.py upstream
python3 client/make_test_media.py upstream/app/src/androidTest/assets/adaptive
cd upstream
./gradlew :app:assembleStableDebug :app:assembleStableDebugAndroidTest
```

Это предварительный выпуск. Пауза DASH и HLS с отдельным звуком приостанавливает чтение данных, сохраняя текущий экспорт. После продолжения он использует те же манифест и выходной файл. Сохранение прогресса между перезапусками приложения ещё не реализовано. После аварийного завершения очередь сохраняется, но не запускается автоматически. Загрузку можно отменить или запустить вручную. Для сохранения сначала требуется место во внутреннем хранилище, затем файл копируется в выбранную папку. Обновление APK из официального репозитория CloudStream отключено из-за другого пакета и сертификата.

Обычная кнопка скачивания открывает выбор качества и озвучки. Автоматическая загрузка остаётся отдельным действием в меню. Расширение включается в APK из того же исходного состояния; при установке проверяется его SHA-256. Уже установленная более новая версия расширения сохраняется.
